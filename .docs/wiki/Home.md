# formpth

formpth is a vector illustration editor, the Illustrator alternative in the NodeMode form family. It draws on artboards with live shapes, the Pen and Curvature tools, Pathfinder, gradients, an appearance stack with live effects, type that outlines to paths, symbols, blends, repeats and image trace, and it reads and writes SVG, PDF, PNG, JPEG, WebP and its own `.fpth` projects.

It runs in a browser against a small Python engine service, or as a desktop app on macOS, Windows and Linux, and agents draw in it through an MCP server with 58 tools.
