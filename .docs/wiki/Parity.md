# Parity

formpth measures itself against Adobe Illustrator row by row, the way formvis measures against Photoshop. `docs/PARITY.md` holds the table: 76 scored rows in nine categories, each graded Full (1), Partial (0.5) or None (0) only when its data model, command, interface and render or export path exist in code, plus 12 additions from plan v0.5.0 and four platform rows, shown and not scored.

At v0.31.0 the score is 73.5 of 76 (96.7 percent): 71 Full, 5 Partial, 0 None, and the additions grade 12 of 12. Independent audits graded the code without this page at v0.16.1 (52 of 76), v0.23.0 (72.5) and v0.30.0 (71, after which the three rows it found short were built). v0.32.0 built ICC colour management, live PDF text, PDF/X-4, an `.ai` writer, DWG through a converter and ray-traced 3D with several lights; the five rows stay Partial on what each still lacks: a Print dialog and the display profile, rasterised masks and meshes in PDF, reading `.ai` without PDF compatibility, DWG without a converter, and Substance materials.
