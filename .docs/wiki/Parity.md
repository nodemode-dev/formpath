# Parity

formpth measures itself against Adobe Illustrator row by row, the way formvis measures against Photoshop. `docs/PARITY.md` holds the table: 59 scored rows in eight categories, each graded Full (1), Partial (0.5) or None (0) only when its data model, command, interface and render or export path exist in code, plus four platform rows shown and not scored.

At v0.16.0 the score is 59 of 59 (100 percent): 59 Full, 0 Partial, 0 None. 3D and Materials closed last, with Map Art, shadows and a tilting Inflate; ray-traced rendering and more than one light stay outside the scored rows, as `docs/PARITY.md` names.
