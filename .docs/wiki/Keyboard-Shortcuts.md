# Keyboard Shortcuts

Ctrl stands for Command on a Mac. Help > Keyboard Shortcuts in the app lists every command and lets you change them.

| Tools | Key |
| --- | --- |
| Selection, Direct Selection | V, A |
| Magic Wand, Lasso | Y, Q |
| Pen, Add, Delete Anchor Point, Anchor Point, Curvature | P, =, -, Shift+C, Shift+~ |
| Rectangle, Ellipse, Line Segment | M, L, \\ |
| Pencil, Paintbrush, Blob Brush, Eraser, Scissors | N, B, Shift+B, Shift+E, C |
| Rotate, Reflect, Scale, Free Transform, Width, Warp | R, O, S, E, Shift+W, Shift+R |
| Eyedropper, Gradient, Mesh, Live Paint, Live Paint Selection, Shape Builder, Blend | I, G, U, K, Shift+L, Shift+M, W |
| Symbol Sprayer, Artboard | Shift+S, Shift+O |
| Type, Touch Type | T, Shift+T |
| Hand, Rotate View, Zoom | H (or hold Space), Shift+H, Z |

| Commands | Key |
| --- | --- |
| New, Open, Save | Ctrl+N, Ctrl+O, Ctrl+S |
| Undo, Redo | Ctrl+Z, Shift+Ctrl+Z |
| Group, Ungroup | Ctrl+G, Shift+Ctrl+G |
| Bring Forward, to Front | Ctrl+], Shift+Ctrl+] |
| Send Backward, to Back | Ctrl+[, Shift+Ctrl+[ |
| Lock, Hide | Ctrl+2, Ctrl+3 |
| Join, Make Clipping Mask, Make Compound Path | Ctrl+J, Ctrl+7, Ctrl+8 |
| Transform Again | Ctrl+D |
| Outline view, Rulers, Guides, Grid, Smart Guides | Ctrl+Y, Ctrl+R, Ctrl+;, Ctrl+', Ctrl+U |
| Zoom In, Zoom Out, Fit Artboard, Actual Size, Fit All | Ctrl+=, Ctrl+-, Ctrl+0, Ctrl+1, Alt+Ctrl+0 |
| Swap Fill and Stroke, Default colours, Fill or Stroke | Shift+X, D, X |
| Colour, Gradient, None | comma, period, slash |
| Screen mode, hide panels | F, Tab |
| Help | F1 |
