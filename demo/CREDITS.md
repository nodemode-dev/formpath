# Demo credits

Nothing in this demo is third-party media. There are no photographs, pictures, templates or sample files: the artwork is drawn by formpath's own tools when the page opens, from the builder in `frontend/src/demos/poster.ts`. "Harbour Lights", Saltmere, the Saltmere Harbour Trust, the programme and every date and figure are invented for the demo.

The brushes and graphic styles it uses are formpath's own built-in libraries (`frontend/src/engine/brush-libraries.ts`). The type is Inter, bundled with the app and listed in `NOTICE.md` with JetBrains Mono, paper.js, opentype.js and xterm.js, the other third-party works inside the script.

The app opens the same demo from Home > Demos, Help > Demos and the `demo-poster` command, with the same builder, so this note covers it too.
