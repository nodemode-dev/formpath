# Demo credits

Nothing in this demo is third-party media. The twelve icons and the logo were drawn for the demo by formpath's own tools when the page opens, from the builder in `frontend/src/demos/icons.ts`; "Brightwater" is an invented name. The type is Inter, bundled with the app and listed in `NOTICE.md` with the other third-party works inside the script.

The app opens the same demo from Home > Demos, Help > Demos and the `demo-icons` command, with the same builder, so this note covers it too.
