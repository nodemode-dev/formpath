# Demo credits

Nothing in this demo is third-party media. The pattern, the blend, the envelope, the 3D badge and the colourways were drawn for the demo by formpath's own tools when the page opens, from the builder in `frontend/src/demos/pattern.ts`; "Salt Works" and every colour are invented. The type is Inter, bundled with the app (this page loads the font files from `demo/assets`, where they are stored once for all three pages) and listed in `NOTICE.md` with the other third-party works inside the script.

The app opens the same demo from Home > Demos, Help > Demos and the `demo-pattern` command, with the same builder, so this note covers it too.
